License-Aware Auth Flow

1.User Access: User accesses APP-X, gets redirected to Keycloak for authentication
2.Federation: Keycloak federates authentication to Microsoft Entra ID
3.JWT Return: Successful authentication returns JWT token with user 'sub' (User ID) to APP-ADMIN
4.License Query: APP-ADMIN queries License Manager for account license status and features
5.Validation Checks:
  • License status (active/expired/trial)
  • Plan features & usage limits
  • Seat availability & allocation
  • Account type (Personal/Business)
6.Usage Tracking: Usage Tracker records feature access and enforces real-time limits
7.Enhanced Access Code: Generated with:
  • User permissions & roles
  • License tier & enabled features
  • Usage limits & quotas
  • Account context & expiration
8.User/Account Setup:
  • Search USER table by Keycloak 'sub'
  • If new user: Create USER + Personal ACCOUNT
  • Cache Access Code in Account table
9.Feature Enforcement: Feature Gate controls access based on license-aware Access Code claims
10.Administration: Admin Portal enables license management, user invitations, and account administration

Key Integration Points & Account Model

🔐 Authentication Layer: Keycloak + Entra ID federation provides enterprise SSO while maintaining license context through user 'sub' mapping
⚡ Real-time Validation: Every token request validates current license status, feature entitlements, and usage limits
📊 Usage Enforcement: API calls, feature usage, and resource consumption tracked against license limits with immediate blocking
🔄 Offline Resilience: Cached Access Codes in Account table enable limited offline functionality with proper expiration handling

Account Creation Logic

New User Flow: Keycloak 'sub' → Search USER table → If not found: Create USER record + Personal ACCOUNT → Link to Access Code

Account Types:
  • Personal: Single-user account created automatically on first login
  • Business: Multi-user account with invitation system and role delegation via APP-ADMIN
Token Attachment: After successful login, JWT Access Code is attached to the ACCOUNT record for both online and offline access scenarios.
